PROJETOS TECH INTEGRADO

Sugestão 1: SISTEMA DE SEGURANÇA PREDITIVA PARA REDES TELECOM
Descrição: Desenvolver um sistema que monitora o tráfego de rede em tempo real, identifica padrões anômalos (possíveis ataques) e otimiza a alocação de recursos de segurança usando algoritmos evolutivos.

Disciplinas envolvidas:
- Computational Intelligence & Algorithm Optimization (otimização)
- Telecommunications & Network Security (aplicação)
- Software Architecture & Design Patterns (arquitetura)
- Open Source Contribution (testes e publicação OSS)

Resultado esperado:
- Sistema funcional que detecta ataques simulados
- Interface de monitoramento em tempo real
- Documentação arquitetural completa
- Relatório de desempenho comparativo
- Apresentação técnica


Sugestão 2: SISTEMA DE ROTEAMENTO ADAPTATIVO PARA REDES 5G
Descrição: Criar um sistema de roteamento inteligente para redes 5G que otimiza dinamicamente as rotas baseado em tráfego, latência e segurança, usando metaheurísticas e distribuído em microsserviços.

Disciplinas envolvidas:
- Computational Intelligence & Algorithm Optimization (núcleo)
- Telecommunications & Network Security (aplicação)
- Software Architecture & Design Patterns (implementação)
- Open Source Contribution (testes e publicação OSS)

Resultado esperado:
- Simulador de rede 5G com roteamento adaptativo
- Melhora na latência comparado a roteamento estático
- Código aberto bem documentado
- Apresentação técnica


Sugestão 3: FIREWALL EVOLUTIVO COM APRENDIZADO DE PADRÕES DE ATAQUE
Descrição: Construir um firewall inteligente que aprende padrões de ataque usando árvores de decisão evolutivas, otimiza regras usando Algoritmos Genéticos e é implementado com arquitetura de microsserviços.

Disciplinas envolvidas:
- Computational Intelligence & Algorithm Optimization (coração)
- Telecommunications & Network Security (segurança)
- Software Architecture & Design Patterns (design)
- Open Source Contribution (testes e publicação OSS)

Resultado esperado:
- Firewall inteligente detectando ataques com 95% de acurácia
- Evolução automática de regras baseado em novos padrões
- Dashboard de monitoramento
- Documentação técnica completa
- Apresentação técnica


Sugestão 4: BOT DE SEGURANÇA PARA CÓDIGO ABERTO COM OTIMIZAÇÃO DE CUSTO
Descrição: Criar um bot automatizado para projetos open source que analisa vulnerabilidades de segurança, sugere correções e otimiza o tempo de resposta usando metaheurísticas.

Disciplinas envolvidas:
- Computational Intelligence & Algorithm Optimization (núcleo)
- Open Source Contribution & Collaboration (plataforma)
- Software Architecture & Design Patterns (implementação)
- Telecommunications & Network Security (segurança de dados)

Resultado esperado:
- Bot integrado a repositórios open source
- Redução no tempo de resposta a vulnerabilidades
- Código aberto com documentação e CI/CD
- Apresentação técnica
